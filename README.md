# The Muse - Interactive Valentine's Experience 🌹

A premium "Phygital" (Physical + Digital) Valentine's Day experience designed as a luxury digital magazine for **Bittu**.

## ✨ Features

### 1. The Lookbook
- **Editorial Layout**: Zig-zag photo gallery with animated gold borders.
- **Micro-Interactions**: Hover effects and smooth scrolling.
- **Tech**: CSS Grid, Flexbox, and CSS Animations.

### 2. Gamified Quiz & Secret Reveal
- **Memory Lane**: 6 questions testing relationship memory.
- **Reward System**: Each correct answer reveals a fragment of a **Secret Phone Number**.
- **Final Puzzle**: The collected digits (`6382377305`) form the key to the physical gift.

### 3. "Will You Be My Valentine?"
- **Smart Logic**: A "Yes/No" interaction where the "No" button shrinks and the "Yes" button grows.
- **Personal Touch**: Cute rejection messages in Hindi (*"sochlo 🥺"*, *"sachme?"*).
- **Celebration**: Gold confetti explosion on acceptance.

## 🚀 Deployment

### Vercel (Recommended)
This project is configured for Vercel. 
1. Run `npx vercel` in this directory.
2. Follow the prompts to deploy.

### Netlify
**Option 1 (Easiest)**: Drag and drop this folder onto [Netlify Drop](https://app.netlify.com/drop).

**Option 2 (CLI)**:
Run `npx netlify-cli deploy --dir=. --prod` in this directory.
